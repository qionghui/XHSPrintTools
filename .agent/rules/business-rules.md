# 业务规则

## 商品标签规范

### 标签尺寸
- 默认尺寸: 50mm × 40mm
- 打印方向: 纵向

### 标签字段与布局

| 位置 | 字段 | 格式说明 |
|------|------|---------|
| 顶部 | 数量 | 仅当数量 > 1 时显示，格式: `2` |
| 第1行 | 成分 | 格式: `成分：{内容}` |
| 第2行左 | 规格 | 格式: `规格：{内容}` |
| 第2行右 | 净重 | 格式: `净重：{内容}` |
| 第3行左 | 产地 | 格式: `产地：{内容}` |
| 第3行右 | 保质期 | 格式: `保质期：{内容}` |
| 第4行左 | 包装日期 | 格式: `包装日期：YYYY-MM-DD` |
| 第4行右 | 等级 | 格式: `等级：{内容}` |
| 第5行 | 储存方式 | 格式: `储存方式：{内容}` |
| 第6行 | 销售商信息 | 固定: `销售商：福建省泉州市保康滋补商行` |
| 第7行 | 联系电话 | 固定: `电话：18396188860（微信同号）` |
| 第8行 | 温馨提示 | 固定: `温馨提示：本店所受农产品属于初级农产品，代客分装，散装称重，包装是为了方便运输赠送。` |

## 组合商品处理规则

### 子项配置格式
```
{子项规格ID}#{数量},{子项规格ID}#{数量},...
```

示例:
```
6710cce9edb7ca0001035123#1,6710cce9edb7ca0001035124#2
```

表示:
- 规格ID `6710cce9edb7ca0001035123` 的商品 1 件
- 规格ID `6710cce9edb7ca0001035124` 的商品 2 件

### 数量计算
如果订单中该组合商品的数量为 N，则每个子项的实际数量 = 子项配置数量 × N

## 订单文件规范

### 文件命名
- 手动打单: `yyyyMMdd_hhnnss手动打单.xlsx`
- 自动下载: 由外部系统命名，必须包含规格ID字段

### 必需字段
- `规格ID`: 商品唯一标识
- `SKU件数` 或 `数量`: 订单数量（可配置字段名）

### 文件处理流程
1. 扫描 `orderExcelDirectory` 目录中的 Excel 文件
2. 读取文件内容，匹配规格ID
3. 生成标签数据
4. 排序标签
5. 打印标签
6. 备份文件到 `bak/` 目录
7. 删除原文件
