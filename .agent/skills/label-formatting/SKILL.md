# 标签格式化技能

## 何时使用此技能

当遇到以下场景时激活本技能：
- 修改标签字段格式（如前缀文字变化）
- 修改固定文案（销售商信息、温馨提示）
- 调整日期格式
- 修改标签尺寸（50mm × 40mm 变更）
- 新增标签显示字段
- 调整标签布局顺序

## 标签标准格式

### 尺寸规格

- **宽 × 高**: 50mm × 40mm
- **打印方向**: 纵向
- **纸张类型**: 热敏标签纸或铜版纸

**如修改尺寸**:
1. 确认打印机驱动中设置对应尺寸
2. 同步更新打印模块中的页面设置参数
3. 测试实际打印效果，避免文字截断

### 字段格式规范

所有可变字段统一使用 `字段名：内容` 格式（注意是中文冒号 `：`）：

| 字段 | 正确格式 | 错误格式 |
|------|---------|---------|
| 成分 | `成分：新疆若羌红枣` | `新疆若羌红枣`（缺前缀） |
| 规格 | `规格：散装称重` | `规格:散装`（英文冒号） |
| 净重 | `净重：250克` | `250克`（缺前缀） |
| 保质期 | `保质期：12个月` | `12个月保质期`（顺序反） |
| 产地 | `产地：新疆` | `来自新疆`（格式错） |
| 等级 | `等级：特级` | `【特级】`（格式错） |
| 包装日期 | `包装日期：2026-08-10` | `2026.08.10`（格式错） |
| 储存方式 | `储存方式：密封冰箱冷藏` | 缺前缀 |

**格式验证正则**:
```
必须匹配:  ^[\u4e00-\u9fa5]+：.+$
成分前缀:  ^成分：.+$
日期格式:  ^包装日期：\d{4}-\d{2}-\d{2}$
```

### 固定文案（严禁随意修改）

**第6行 - 销售商信息**:
```
销售商：福建省泉州市保康滋补商行
```

**第7行 - 联系电话**:
```
电话：18396188860（微信同号）
```

**第8行 - 温馨提示**:
```
温馨提示：本店所受农产品属于初级农产品，代客分装，散装称重，包装是为了方便运输赠送。
```

> ⚠️ 以上三条为法律合规信息，修改前必须获得业务负责人书面确认！

## 日期格式化

### 标准格式

- **格式**: `YYYY-MM-DD`（横杠分隔，4位年2位月2位日）
- **示例**: `2026-08-10`, `2026-01-05`

### Delphi 实现

```pascal
// 默认使用当前日期
FormatDateTime('yyyy-mm-dd', Now);

// 自定义日期输入
function GetPackDate: string;
var
  InputDate: TDateTime;
begin
  if DIYDateMode then
  begin
    InputDate := StrToDateDef(UserInput, Now);
    Result := FormatDateTime('yyyy-mm-dd', InputDate);
  end
  else
  begin
    Result := FormatDateTime('yyyy-mm-dd', Now);
  end;
end;
```

### 常见日期格式错误

| 错误格式 | 正确格式 | 说明 |
|---------|---------|------|
| `2026/8/10` | `2026-08-10` | 分隔符和补零 |
| `2026.08.10` | `2026-08-10` | 分隔符应为横杠 |
| `26-08-10` | `2026-08-10` | 年份必须4位 |
| `2026年8月10日` | `2026-08-10` | 只保留数字格式 |

## 数量字段特殊规则

**仅当数量 > 1 时**，在标签顶部显示数量：
```
数量 = 1 → 不显示数量
数量 = 2 → 显示 "2" (或 "数量:2")
数量 = 5 → 显示 "5"
```

## 修改流程检查清单

修改标签格式后，必须完成以下验证：

- [ ] 所有字段使用中文冒号 `：` 而非英文冒号 `:`
- [ ] 日期格式为 `YYYY-MM-DD`，月份日期均为 2 位
- [ ] 固定文案三条（销售商/电话/温馨提示）完全一致，无错别字
- [ ] 空字段（如某商品没有等级）处理正确：要么不显示，要么显示默认值
- [ ] 实际打印测试一张，检查：
  - 文字无截断
  - 边距合理（左右至少 1mm）
  - 可扫描（如有条码）
  - 多标签连续打印不偏移
- [ ] 保存一张打印样例存档（命名：`label-sample-YYYYMMDD.png`）
