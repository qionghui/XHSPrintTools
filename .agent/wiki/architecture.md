# 项目架构说明

## 整体分层

```
┌─────────────────────────────────────────────────────┐
│                   表现层 (UI)                        │
│  Delphi VCL 窗体 (UMain.pas / UMain.dfm)            │
│  - TabSheet1: 手动打单 / 商品管理                    │
│  - TabSheet2: 打印进度 / 批量重打                    │
└───────────────────────┬─────────────────────────────┘
                        │
┌───────────────────────▼─────────────────────────────┐
│                   业务逻辑层                         │
│  - 规格ID匹配 (goods.xlsx 查找)                      │
│  - 组合商品展开 (子项配置解析)                        │
│  - 标签排序 (成分/规格/净重/等级)                    │
│  - 免打数量过滤 (exempt_config.json)                 │
└───────────────────────┬─────────────────────────────┘
                        │
┌───────────────────────▼─────────────────────────────┐
│                   数据访问层                         │
│  - Excel COM 读写 (LoadExcelToGrid / SaveGridToExcel)│
│  - JSON 配置读写 (config.json / exempt_config.json)  │
│  - 文件系统操作 (扫描/备份/删除)                      │
└─────────────────────────────────────────────────────┘
```

## 核心组件交互

### 手动打单流程

```
用户操作                    TForm1                     Excel
   │                         │                          │
   │ 点击商品行数量列(左键)  │                          │
   │────────────────────────▶│                          │
   │                         │ CurrentValue++           │
   │                         │ StringGrid1 更新显示     │
   │                         │                          │
   │ 点击 [保存手动打单]     │                          │
   │────────────────────────▶│                          │
   │                         │ SaveGridToExcel(SavePath)│
   │                         │─────────────────────────▶│
   │                         │                          │ Workbooks.Add
   │                         │                          │ 遍历行，数量>0写入
   │                         │                          │ SaveAs
   │                         │  保存成功提示(省略)       │
   │                         │◀─────────────────────────│
   │                         │                          │
   │                         │ ClearFilterAndNum        │
   │ 第1列数量清空           │◀─────────────────────────│
   │◀────────────────────────│                          │
```

## 数据流走向

### 订单文件处理流

```
外部订单 (xlsx)
     │
     ▼
orderExcelDirectory (config.json 配置)
     │
     ▼
Python 或 Delphi 扫描
     │
     ├── 规格ID ────────┐
     │                   ▼
     │            goods.xlsx (商品配置)
     │                   │
     ▼                   ▼
  数量字段 ──────▶ 标签数据组装
                       │
                       ▼
                  组合商品展开 (递归)
                       │
                       ▼
                  排除免打数量
                       │
                       ▼
                  四级排序 (成分/规格/净重/等级)
                       │
                       ▼
                  生成打印输出 (PrintTools.exe)
                       │
                       ├──────────────────┐
                       ▼                  ▼
               打印机 (物理标签)     latest_print_file.xlsx
                       │
                       ▼
                  orderExcelBackupDirectory (bak/*.xlsx)
                       │
                       ▼
               删除原订单文件
```

## 文件依赖关系

```
PrintTools.exe (根目录)
    │
    ├── goods.xlsx              (必需，商品配置)
    ├── config.json             (必需，路径和字段映射)
    ├── exempt_config.json      (可选，免打配置，不存在则自动创建)
    └── latest_print_file.xlsx  (可选，由 Python 脚本生成)

PrintTools/ (源码目录)
    ├── PrintTools.dpr          (项目入口)
    ├── PrintTools.dproj        (IDE 项目配置，包含编译选项)
    ├── PrintTools.res          (资源文件，图标/版本信息)
    ├── UMain.pas               (核心代码，约 800 行)
    └── UMain.dfm               (窗体布局，控件属性)

bak/ (备份存档)
    └── {timestamp}手动打单.xlsx  (按时间命名，永不删除)
```
