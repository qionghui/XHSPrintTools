# 项目需求规格说明

## 1. 项目背景

福建省泉州市保康滋补商行主要经营农产品、干货等初级农产品的分装销售。随着电商订单量增长，手动填写和粘贴标签的方式效率低下且容易出错，需要一套自动化的标签打印工具。

## 2. 项目目标

- 自动读取电商平台导出的 Excel 订单文件
- 根据商品配置自动生成标准化商品标签
- 支持组合商品自动拆分子项标签
- 按拼音排序标签，提高分装效率
- 自动打印标签并备份订单数据

## 3. 功能需求

### 3.1 核心功能

| 编号 | 功能模块 | 优先级 | 说明 |
|------|---------|--------|------|
| F-001 | 订单文件自动扫描 | P0 | 每 10 秒扫描订单目录，发现新文件自动处理 |
| F-002 | Excel 订单解析 | P0 | 读取 xlsx/xls 格式订单，提取规格ID和数量 |
| F-003 | 商品信息匹配 | P0 | 根据规格ID从 goods.xlsx 查找商品详情 |
| F-004 | 组合商品展开 | P0 | 有子项配置的商品按配置拆分为多个标签 |
| F-005 | 标签排序 | P1 | 按成分→规格→净重→等级排序 |
| F-006 | 标签打印 | P0 | 调用打印模块输出 50mm×40mm 标签 |
| F-007 | 订单备份 | P0 | 处理完的订单移动到 bak 目录 |
| F-008 | 手动打单界面 | P1 | Delphi GUI 手动选择商品生成订单 |
| F-009 | 免打数量配置 | P2 | 某些商品默认免打若干份（避免重复打） |
| F-010 | 自定义打印日期 | P2 | 支持指定包装日期而非当天 |

### 3.2 手动打单功能 (Delphi GUI)

1. **TabSheet1 - 商品配置管理**:
   - 加载 goods.xlsx 到 StringGrid
   - 点击第1列（数量）左键+1 右键-1
   - 点击第2列（免打）左键+1 右键-1，自动保存配置
   - 拼音搜索框实时筛选商品
   - 底部 CheckListBox 快速选择商品类别

2. **TabSheet2 - 最新打印预览**:
   - 定时加载 latest_print_file.xlsx
   - 点击某行快速定位（已打/未打标记）
   - 支持批量重打功能

## 4. 非功能需求

| 编号 | 需求 | 说明 |
|------|------|------|
| NF-001 | 并发安全 | 使用 application.lock 防止多实例同时处理订单 |
| NF-002 | 数据完整 | 订单处理成功后才备份并删除原文件，失败时保留 |
| NF-003 | 错误提示 | Excel 操作失败时给出中文错误提示，含文件路径 |
| NF-004 | 性能 | 单次处理 500 行订单 < 5 秒（不含打印时间） |
| NF-005 | 兼容性 | 支持 Windows 7 及以上系统 |

## 5. 数据需求

### 5.1 输入数据

- **订单 Excel**: 规格ID + 数量字段（可配置列名）
- **goods.xlsx**: 商品配置表，规格ID为唯一键
- **config.json**: 路径配置和字段映射
- **exempt_config.json**: 各规格ID免打数量

### 5.2 输出数据

- **bak/yyyyMMdd_*.xlsx**: 订单备份
- **latest_print_file.xlsx**: 最近一次打印内容
- **PrintTools 打印输出**: 物理标签纸张

## 6. 范围约束

### 在范围内 (In Scope)
- 农产品/干货类商品标签
- 规格ID匹配的订单格式
- 50mm × 40mm 标签尺寸
- Windows 平台运行

### 不在范围内 (Out of Scope)
- 其他行业标签（如物流面单、价签）
- macOS / Linux 平台
- 网络打印 / 远程打印服务
- 条码 / QR 码生成（当前无此需求）
